### Stream 2: Contract Tests

Verify public API contracts won't regress.

#### `test_org_trending_contracts.py`
- **TrendingSnapshot**: construction with all fields, defaults, field types
- **TrendingDelta**: construction, field semantics (signed integers)
- **OrgReportTrending**: `to_comparison()` returns correct type or None
- **`discover_snapshots()`**: return type is `list[TrendingSnapshot]`, ordered oldest-to-newest, respects window_size
- **`compute_deltas()`**: returns `list[TrendingDelta]`, len == len(snapshots) - 1, delta signs correct
- **`compute_drift_scores()`**: returns `dict[str, float]`, values in [0.0, 1.0]
- **`build_trending()`**: returns `OrgReportTrending | None`, None when < 2 snapshots
- **Snapshot utils public API**: `parse_snapshot_timestamp()`, `snapshot_epoch()`, `chronological_snapshot_sort_fields()`, `org_report_snapshot_metadata()` — verify return types and shapes
- **Cache public API**: `save_org_report_snapshot()` creates file, `prune_org_report_snapshots()` respects keep_last
- **Writer public API**: each of the 7 `write_org_report_*()` functions accepts `trending=None` without error

#### `test_cli_diff_contracts.py`
- **List commands**: each `_fetch_*()` factory returns a callable with `(cja, is_machine_readable) -> Optional[str]` signature
- **Config commands**: `_resolve_config_path()` returns `Path`, `_validate_credentials()` returns bool
- **Execution**: `_resolve_output_path()` returns `Path` or raises
- **Diff/git**: `git_diff_cached()` returns `str | None`, `git_commit()` returns commit SHA or raises

### Stream 3: Adversarial Input Tests

#### `test_org_trending_adversarial.py`

**Malformed snapshot files:**
- Truncated JSON (partial write)
- Valid JSON but wrong schema (array instead of object, missing required keys)
- Empty file (0 bytes)
- Binary garbage
- Extremely large snapshot (10k data views, 100k components)
- Snapshot with all-zero metrics
- Snapshot with negative metric values

**Corrupted cache directories:**
- Cache dir exists but is a file
- Cache dir with no read permission
- Cache dir with mixed valid/invalid snapshot files
- Snapshot file that is a symlink to /dev/null
- Empty subdirectories in cache root

**Timestamp edge cases:**
- Future timestamps (year 2099)
- Epoch 0 / Unix epoch
- Invalid format strings ("not-a-date", empty string)
- Timezone-aware vs naive datetime mixing
- Duplicate timestamps across snapshots

**Race conditions in OrgReportLock:**
- Lock file already held (simulate concurrent acquisition)
- Lock file is stale (process died)
- Lock directory doesn't exist
- Lock file is a directory

**Org ID edge cases:**
- Unicode org IDs (CJK characters, emoji, RTL text)
- Org IDs with path separators (`../`, `/`, `\`)
- Empty string org ID
- Very long org ID (1000+ characters)
- Org ID with null bytes

**Drift score robustness:**
- Single snapshot (should return empty/None)
- Two identical snapshots (drift should be 0.0)
- Snapshot with data view appearing then disappearing
- All data views replaced between snapshots (maximum drift)
- Division-by-zero scenarios (all metrics zero)

**Overall trending pipeline stress tests:**
- 50+ snapshot window (verify performance and correctness)
- Snapshots with progressively degrading data quality
- Mixed snapshot versions (future-proofing)
- Trending with explicit_history_file pointing to non-existent path
- Trending with current_snapshot that duplicates an existing cached snapshot

## Success Criteria

1. All modules in scope reach their target coverage percentages
2. Overall project coverage >= 96% (maintained or improved)
3. All 3 new test files pass
4. No existing tests broken
5. `uv run ruff check src/ tests/` passes clean

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Some uncovered lines are genuinely unreachable | Mark with `# pragma: no cover` after confirming, document why |
| Adversarial tests may be slow | Use `@pytest.mark.slow` for expensive scenarios, keep defaults fast |
| Mocking git subprocess calls is fragile | Use the existing mock patterns in `test_cli_command_handlers.py` |
| Test count changes require README updates | Run `--collect-only` at end, update counts per CLAUDE.md checklist |
