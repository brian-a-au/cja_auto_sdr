# v3.5.11 — CI Lint Completeness + DataFrame Truthiness Hardening

**Date:** 2026-04-03
**Type:** Patch release
**Theme:** Close gaps exposed by the v3.5.8–v3.5.10 hardening cycle

## Context

The v3.5.8–v3.5.10 releases fixed inventory-summary bugs (broken cjapy calls, bare DataFrame truthiness checks), added branch protection requiring 10 CI checks, and verified all CLI surfaces via production smoke testing. This follow-up patch closes the remaining gaps surfaced during that work.

## Scope

Five changes, all non-functional or defensive:

### 1. Add unlinted scripts to CI lint (HIGH)

**Problem:** `scripts/create_sample_outputs.py` and `scripts/stress_test.py` are shipped in the repo and listed in CLAUDE.md's scripts inventory, but are excluded from the `ruff` CI job in `lint.yml`. They have ~444 accumulated ruff violations invisible to CI.

**Fix:**
- Add both scripts to `ruff check` and `ruff format --check` commands in `.github/workflows/lint.yml:30-32`
- Run `uv run ruff check --fix` and `uv run ruff format` to auto-fix violations
- Manual review for any non-auto-fixable issues

**Files:** `.github/workflows/lint.yml`, `scripts/create_sample_outputs.py`, `scripts/stress_test.py`

### 2. Advance ruff target-version to py314 (HIGH)

**Problem:** `pyproject.toml:82` pins `target-version = "py313"` due to 3 forward-annotation sites triggering UP037 rewrites. The runtime floor is already `>=3.14`, so the config should match.

**Fix:**
- Remove quoted forward annotations at:
  - `src/cja_auto_sdr/core/config.py:169` — `-> "SDRConfig"` → `-> SDRConfig`
  - `src/cja_auto_sdr/generator.py:1255` — `snapshot: "DataViewSnapshot"` → `snapshot: DataViewSnapshot`
  - `src/cja_auto_sdr/generator.py:1261` — `-> "DataViewSnapshot"` → `-> DataViewSnapshot`
- Change `target-version = "py313"` → `"py314"` in `pyproject.toml`
- Remove the explanatory comment above it

**Files:** `pyproject.toml`, `src/cja_auto_sdr/core/config.py`, `src/cja_auto_sdr/generator.py`

### 3. Fix bare truthiness on inventory fields in diff/git.py (MEDIUM)

**Problem:** `diff/git.py:108,119,142,144,146` uses `if snapshot.calculated_metrics_inventory:` and `if snapshot.segments_inventory:` — bare truthiness checks on `list[dict] | None` fields. An empty list `[]` (valid — data view has zero calculated metrics) is falsy, so the git writer would silently skip writing the inventory JSON file and omit the metadata count. The model already provides `has_calculated_metrics_inventory` / `has_segments_inventory` properties that use `is not None`.

**Fix:** Replace all 5 bare truthiness checks with `is not None`:
- Line 108: `if snapshot.calculated_metrics_inventory is not None:`
- Line 119: `if snapshot.segments_inventory is not None:`
- Line 142: `if snapshot.calculated_metrics_inventory is not None or snapshot.segments_inventory is not None:`
- Line 144: `if snapshot.calculated_metrics_inventory is not None:`
- Line 146: `if snapshot.segments_inventory is not None:`

**Files:** `src/cja_auto_sdr/diff/git.py`

### 4. Add --inventory-summary to README common use cases (MEDIUM)
